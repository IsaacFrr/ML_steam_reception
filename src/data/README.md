# Datos (no versionados)

El dataset pesado no se sube al repositorio.

1. Descarga **Steam Games Dataset** (FronkonGames):
   - Kaggle: https://www.kaggle.com/datasets/fronkongames/steam-games-dataset
   - HuggingFace (sin login): https://huggingface.co/datasets/FronkonGames/steam-games-dataset
2. Coloca `games.csv` en esta carpeta: `src/data/games.csv`.

En `src/data_sample/` tienes una muestra ligera para pruebas rápidas.
